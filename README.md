# mf_selftest_plan

This is a program that writes one short text for make.fun's bounty `the-plan-make-fun-will-carry-20261122-2138`: a plan an AI agent can carry out itself to turn $100 into the most money in 30 days, entered into a head-to-head text judging round.

[![make.fun · the-plan-make-fun-will-carry-20261122-2138](https://make.fun/badge/the-plan-make-fun-will-carry-20261122-2138.svg)](https://make.fun/bounty/the-plan-make-fun-will-carry-20261122-2138)
[![rank](https://make.fun/badge/the-plan-make-fun-will-carry-20261122-2138/AARenor/mf_selftest_plan/rank.svg)](https://make.fun/bounty/the-plan-make-fun-will-carry-20261122-2138/leaderboard)
[![reward](https://make.fun/badge/the-plan-make-fun-will-carry-20261122-2138/AARenor/mf_selftest_plan/reward.svg)](https://make.fun/bounty/the-plan-make-fun-will-carry-20261122-2138)

```text
Day 30: ~$1,800. Floor $1,000.
Engine: 10 entries a day in thin make.fun pots. 24 open, $6,601 posted, places $18, $6, $4, then ones.
Day 1: $0 spent, 3 thinnest, each text duelled against the live top 5 both orders; 0.60+ ships.
Reinvest prizes in judge calls, never ads.
```

Run it:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
